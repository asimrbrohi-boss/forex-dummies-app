# Forex Dummies App

A beginner-friendly forex trading education and demo-trading app built as a progressive web app, so it works well on desktop and Android devices.

Features:
- Beginner lessons on pips, spreads, risk, and stop-loss
- Demo account dashboard with fake balance and P/L tracking
- Trade form for buy/sell orders on major currency pairs
- Simple market watch panel with simulated live price movement
- Risk calculator for position sizing
- Trade journal and win-rate summary
- Installable PWA support for Android-like mobile experience

## Run locally
Open `index.html` in a browser, or serve the folder with a simple static server.

Example:

```bash
python -m http.server 8000
